\section{The Validation-Locked Protocol}
\label{sec:protocol}

\subsection{What the protocol asserts}
One rule, applied without exception: every decision that could be tuned ---
preprocessing parameters, standardisation statistics, architecture, probe
regularisation, learning rate, freeze depth, training epoch, temperature,
abstention threshold, and the choice of method itself --- is made on data drawn
from the training session only. Held-out session labels enter exactly once, to
compute the numbers reported here.

This is stronger than reserving a test set. The usual failure is not touching
test labels but selecting among many configurations by their test performance
and reporting the winner; here the selection split is a subset of the training
session and the held-out session is a different recording day.

\subsection{How it is enforced}
Every retained result row carries an \method{eval\_labels\_used\_for\_selection}
field, written by the runner and never by hand.
\method{audit\_leakage\_fields.py} refuses to load any artifact where that field
is absent or true, and the selective-prediction stage re-checks the same field
inside each probability file before computing a single row. The audit is
therefore a property of the artifact format rather than of author discipline: a
run that violated the rule could not be loaded by the code that builds these
tables.

\subsection{Splits}
Model parameters are fit on 80\% of the training session; every hyperparameter,
temperature, threshold and checkpoint is selected on the remaining 20\%; the
held-out session is used once. On BCI~IV-2a this is 230 fit, 58 selection and 288
held-out trials for eight of nine subjects; subject~9 yields 221, 56 and 264
after artifact rejection. The 58-trial selection split is small, and
Section~\ref{sec:results} shows that this is what makes fine-tuning unstable
under the reference recipe.

\subsection{Two preprocessing paths}
\label{sec:twopaths}
The supervised baseline consumes 8--30\,Hz data at 250\,Hz, per-channel
z-scored using fit-split statistics. The foundation models consume
0.1--75\,Hz data at 200\,Hz with a 50\,Hz notch, scaled in microvolts. Each
model receives the input it was built for; feeding a foundation model
8--30\,Hz data would place it outside its pretraining distribution for reasons
unrelated to the question, making any resulting deficit unfalsifiable. The
adapter raises \method{BandMismatchError} rather than silently accepting the
wrong band.

The cost of two paths is that the model comparison is confounded with
preprocessing. Section~\ref{sec:decomp} measures that confound rather than
assuming it away.

\subsection{Channel identity, determinism and provenance}
Foundation models index a learned per-electrode embedding, so channel identity
is part of the input contract rather than metadata; the canonical montage is
reconstructed and verified against all 18 source files. Determinism is on by
default, and a platform fingerprint recording device, library versions and the
determinism flags actually in force is written into every run record, so
results from different backends cannot be silently pooled. All numbers reported
here come from the deterministic CPU backend.
